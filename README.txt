OMKAR COURIER SERVICES - FINAL DHL LOGO DESIGN

SETUP (Windows)
1. Extract this ZIP.
2. Open the extracted folder named OmkarCourierServices_Final.
3. Click the folder address bar, type cmd, and press Enter.
4. Run: npm install
5. Run: npm start
6. Open http://localhost:3000

IMPORTANT
- Run npm commands in the folder that contains package.json and server.js.
- Existing Trackon, India Post, MOVIN and TEJ tracking logic is retained.
- DHL is displayed in place of Blue Dart as requested; live DHL tracking is not connected in this project yet.
- Complete India Post CAPTCHA manually when the official tracking browser opens.
